# Operation Shadow Transfer — Synthetic Demonstration Dataset

**DEMONSTRATION DATA ONLY — NOT REAL POLICE OR CUSTOMER EVIDENCE.**

All names, telephone numbers, email addresses, account references, vehicle identifiers, event records and source documents in this scenario are fictional and have been altered for software testing. The `.invalid` email domain and zero-prefixed phone identifiers are intentionally non-operational placeholders.

## Scenario purpose

A fictional financial customer reports unexpected transfers. The dataset contains coordinated but deliberately imperfect CDR, GPS, bank, FIR-style incident, email, chat, social-post and investigator-annotation records. The objective is to test whether the prototype can parse the supplied sources, preserve their file/record references, correlate matching identifiers and produce a timeline while retaining timestamp uncertainty.

## Interpretation cautions

- Names and identifiers are synthetic scenario labels, not verified real-world identities.
- A phone/device/location relationship is not proof of a person's presence or conduct.
- Transfers and communications are scenario observations, not evidence that an offence occurred.
- Some timestamps intentionally lack a timezone; those records must remain on an unverified source clock.
- Annotation rows are test metadata and should be displayed separately from independently acquired evidence.
- SHA-256 values generated by the app record the file digest on upload; they do not prove pre-upload authenticity or chain of custody.

## Files to upload

Upload these eight files into one new case. The README is for instructions and is not an evidence input.

1. `cdr.csv` — synthetic call detail records.
2. `gps.csv` — synthetic GPS and telecom location observations.
3. `transactions.csv` — synthetic account transfers.
4. `fir.txt` — synthetic incident report and scenario context.
5. `emails.txt` — three synthetic email messages.
6. `chat.txt` — synthetic chat messages.
7. `social.json` — synthetic social-media posts.
8. `annotations.csv` — scenario-only investigator annotation links.

Recommended case name: `Operation Shadow Transfer`. The application generates the case ID; copy it from the reconstruction page URL before running the replay script.

Do not upload real personal, financial, communications or law-enforcement records.
